# GEO-Detective academic project page

This version is based on Eliahu Horwitz's [Academic Project Page Template](https://github.com/eliahuhorwitz/Academic-project-page-template) and is ready for GitHub Pages.

## Publish in the existing repository

1. Copy this folder's contents into `docs/` in `zxyreal/GEO-Detective`.
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/docs` folder, then save.
5. The expected page URL is `https://zxyreal.github.io/GEO-Detective/`.

## Update later

- Replace `static/pdfs/paper.pdf` when the paper changes.
- Replace both `static/pdfs/poster.pdf` and its preview `static/images/poster.png` when the poster changes.
- Update the Paper, Code, Poster, and BibTeX links in `index.html` if needed.

The template attribution and CC BY-SA 4.0 website-source license are retained in the footer.
